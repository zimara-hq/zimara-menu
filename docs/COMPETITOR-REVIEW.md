## التجارب والرحلات العامة

- [QRMenu demo](https://qrmenutest.qrmenu.sa/#/): منيو مرسوم بأقسام وبحث وسلة؛ عرض تحذير بالإنجليزية بأن البيانات للعرض ولا تعالج طلبات أو معاملات حقيقية. وجدت أصنافًا وصورًا وأسعار «From». هذا إثبات واجهة عامة، لا تجربة مدفوعة مكتملة.
- [azzzz](https://azzzz.qrmenu.sa/#/): صفحة منشأة عامة تعرض اسمًا ووصفًا وساعات عمل وصنفًا بسعر 15.00 وسعرات 500؛ ظهرت حالة «closed now». هذه بيانات صاحب الصفحة وليست مشكلة منصة مثبتة.
- [التسجيل بالرابط المرفق](https://qrmenu.sa/register?plan=ee5f500c-ac23-4c89-9e5d-e0d005588118): عرض خمس مراحل OTP ← بيانات المكان والمالك ← مراجعة الاشتراك ← الدفع ← التفعيل، لكنه عرض «المجانية» في هذه الجلسة؛ لم نكمل تحقق الهاتف. لا نفترض أن معرف الخطة المرسل ما زال صالحًا أو يثبت سعرًا بعينه.
- [دخول الإدارة](https://qrmenu.sa/admin/login?returnUrl=%2Fguide): وصلنا إلى نموذج بريد/كلمة مرور واستعادة؛ **لم ندخل لوحة الإدارة** ولا دليل المستخدم المحمي.
- عرض بيجري العام يصف نفسه بأنه محاكاة توضيحية لا طلبًا أو إشعار نظام حقيقيًا، ويعرض محاكاة Live Activity. تقليد المشهد بصريًا لا يكشف تنفيذ المنتج أو يثبت وصول تنبيه إلى هاتف مقفل.
- Pager App يشرح علنًا حدود iPhone: صفحة مفتوحة أو إضافة للشاشة الرئيسية مع إذن Push. كما يذكر إعادة الاتصال وفحصًا احتياطيًا للحالة. هذه ادعاءات تسويقية محددة، ولم ننشئ تذكرة فعلية عنده.

## أين يمكن لزيمارا أن تتميز دون ادعاء تفوق غير مختبر؟

| فرصة قابلة للتنفيذ | معيار قبول زيمارا |
|---|---|
| فصل المنيو العام عن شاشة الربط الخاصة | لا تعيد أي واجهة عامة رمز تذكرة؛ رابط جهاز العرض قابل للإلغاء، ويختفي QR فور الربط |
| حالة نداء مفهومة على ثلاثة أجهزة | «مرتبط/جاهز/رآه العميل/استلم» حالات منفصلة، تستعاد بعد تحديث الصفحة وانقطاع الشبكة |
| انتقال تدريجي من العرض إلى الطلب | تشغيل الطلب لكل فرع؛ أسعار يحسبها الخادم؛ منع تكرار إرسال الطلب؛ الدفع عند الكاشير واضح |
| ولاء يمكن تدقيقه | دفتر حركات، هوية موظف، مفتاح منع التكرار، واستبدال ذري لا يصرف المكافأة مرتين |
| تخصيص يخدم سرعة التشغيل | استيراد مع معاينة الأخطاء، حفظ الهوية مرة واحدة لجميع الشاشات، وتجربة لمس RTL سهلة للموظف |
| صدق حالة الربط | Wallet/Push/POS/الدفع والفوترة تعرض حالة حقيقية؛ لا زر نجاح وهمي ولا وعد بصوت مضمون |
| شفافية التكلفة | سعر شهري/سنوي وضريبة وحدود فروع وإضافات واضحة؛ الإلغاء واضح؛ لا إخفاء تكلفة SMS أو POS |

هذه **أهداف تميّز مقترحة**؛ ليست استنتاجًا بأن المنافسين يفتقدونها داخليًا. لا يمكن إثبات نقصهم من صفحات تسويق عامة فقط. المقابلات مع أصحاب المقاهي واختبارات الاستخدام المقارنة مهمة قبل ادعاء تفوق تجاري.
