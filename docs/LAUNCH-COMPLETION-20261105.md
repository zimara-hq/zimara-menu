## التحقق

- 169 اختبار وحدة/تكامل للخادم نجح، دون استدعاءات مزود فعلية.
- رحلة المتصفح المتصل: 14 تحققًا في جلسات مستقلة، مع الاستلام والتقييم والولاء.
- مركز التشغيل والمطبخ والطاولات: 4 تحققات متصفح، بعرض 390px ومن دون أخطاء JavaScript.
- استوديو المشترك: 5 تحققات متصفح للتخصيص وإعادة الترتيب والنشر واستعادة خطأ الحفظ.
- PWA: 5 اختبارات وحدة وفحص Chromium للتثبيت والانقطاع وإعادة المحاولة؛ لم تُخبأ صفحات أو بيانات API الخاصة.
- تصدير Wrangler فعلي لقاعدة محلية مؤقتة واستعادة SQLite منفصلة: سلامة القاعدة والمراجع نجحت. هذا لا يثبت استعادة Cloudflare الإنتاجية أو ملفات R2.
- تحديث Graphify محلي دون LLM نجح؛ استخراج SQL غير متاح لغياب tree_sitter_sql، ولا يمنع تطبيق migrations واختبارها في D1/SQLite.

الأدلة المحلية في `output/launch/` وسجلات `output/launch-*.log`. نتائج CI والمعاينة المنشورة تُراجع على SHA الإصدار نفسه، وتُضاف إلى بيان الإصدار بعد النشر.
