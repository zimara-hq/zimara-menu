# زيمارا منيو — المرحلة الأولى: منيو العميل

هذه المرحلة تطوّر منيو العميل فوق آخر `main` بعد PR #33، ولا تعيد بناء منصة الاشتراك أو الاستوديو. النشر المقصود هو Worker المراجعة المعزول فقط. المراجع الأصلية الثلاثة محفوظة في `docs/plans/`، وخريطة الملاحظات الأربع عشرة في `NEXT-LEVEL-PLAN.md`.

## ما تغيّر

- غلاف رفيع، هوية بسطر واحد يتكيف حجمها مع الاسم، وإفصاح كامل للاسم والوصف. تظهر أربعة أصناف في تجربة شبكة 390×844؛ بداية أول بطاقة عند 328.6px بدل 528.6px في التجربة المرجعية السابقة. هذا قياس لتلك الوصفة والمحتوى، وليس ضمانًا لكل اسم أو صورة مخصصة.
- شبكة وقائمة ونص من وصفة المنشأة المنشورة نفسها، مع إضافة مباشرة ومساحة لمس مناسبة، وتفاصيل مستقلة حتى عند إيقاف الطلب.
- معرض صور وخيارات وإضافات ومسببات حساسية. توصيات مبنية على طلبات فعلية بحد أدنى ثلاثة طلبات داعمة، أو اختيارات التاجر المصرّح بها؛ لا توصيات ولا شعبية مصطنعة.
- بحث وفلاتر نباتي/نباتي صرف/خالٍ من الغلوتين والسعر والسعرات. البيانات المجهولة تبقى مجهولة. الأكثر طلبًا اليوم يحسب الطلبات الحقيقية بتوقيت الرياض.
- تحديث التوفر والأسعار دون فقد نص ملاحظة العميل أو موضع المؤشر. تغيّر السعر يتطلب مراجعة العميل، والخادم يرفض عرض سعر قديم بـ409 قبل إنشاء الطلب؛ إعادة المحاولة لنفس الطلب ترجع إيصالها الأصلي.
- تحكم صاحب المنشأة بمعرض الصور والوسوم الغذائية والمكملات وجدول التصنيف لكل فرع، بما يشمل الفترات التي تتجاوز منتصف الليل. تعديل المسودة لا يغيّر التصميم العام قبل النشر.
- 27 رسمة أصلية و81 نسخة WebP متجاوبة، مرتبطة بالعينات الجديدة فقط؛ لم تُعد تهيئة بيانات منشآت حقيقية. التفاصيل والترخيص في `MENU-ASSETS.md`.
- تحويل خطّي Tajawal/Jakarta الافتراضيين إلى WOFF2 حقيقي مع الحفاظ على المحارف والترخيص. الخطوط المخصصة تبقى ملك وصفة المنشأة. Node >=24 واختبارا متصفح جديدان في CI.
