# Visual and motion research

Use this skill for requests for fresh visual directions, expressive components, or purposeful animation, including ZIMARA projects. Preserve the user's existing brand and technical choices. Read brand assets when available; do not invent brand facts.

Browse https://dribbble.com/shots/popular/web-design for composition and art direction, and https://uiverse.io for interactive component ideas. Discover Motionsites and 21st tools when connected. Verify tool availability; a configured MCP entry alone is not proof of a working connection. If unavailable, use the public reference pages and state the limitation.

Select references that fit the audience and task. Explain the relevant principles briefly, then create an original implementation combining those principles with the user's content. Do not copy protected artwork or claim authorship of third-party work. Check the license of any code or asset before reuse, preserve required attribution, and link to references used.

Make motion serve hierarchy, orientation, or feedback. Support reduced motion and keyboard interaction; check RTL when Arabic is used. Verify the result at mobile and desktop sizes with the available browser tools. Deliver concrete work when requested, not only inspiration links. Do not promise rendering or export capabilities until verified.
