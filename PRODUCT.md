# ZIMARA Menu

Saudi Arabic-first, bilingual standalone menu/pager/web-loyalty product. The central verified journey is a cashier creating a pager with an independent invoice reference, a customer linking on a private counter display, a ready call, a separate acknowledgment and pickup, then rating and loyalty. Public profile/menu links must never disclose pager bearer credentials.

The current release is a synthetic-data trial/review build, not a commercial launch. Source authority and unresolved business/provider decisions: docs/INPUTS.md. Runtime/API contracts and security boundaries: docs/INTEGRATIONS.md and docs/SECURITY-AUDIT.md. Operational UI contract: UX-CONTRACT.md; visual palette and canonical component owners: DESIGN.md.
